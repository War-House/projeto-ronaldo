Retry com espera crescente, Dead Letter Queue por consumidor e idempotência por eventoId, seguindo a lógica do comum.js e dos três consumidores.

Esta página simula o comportamento do código no navegador, sem conexão com o RabbitMQ. As mensagens de log seguem o formato dos arquivos. Na apresentação, mostre a página para explicar e rode os comandos de cada cenário no terminal para a execução real (RabbitMQ no ar e consumidores ligados).
